# KoK 5.3

## 这一版

- **截图独立**：`⌥C` 框选屏幕区域后，原图直接进剪贴板，不再自动打开提问面板；
  右键菜单也加入了「截图并复制」。截完可以粘贴到任意 App，或按住 `⌘3` 把它当作提问上下文。
- **翻译优先面板**：翻译是唯一一键动作；提问/语音是第二入口。
- **界面收口**：引擎与翻译方向合成单菜单；翻译卡片 240、语音 HUD 320、提问 420；
  空状态居中；「新对话」只在提问形态出现。
- **合并了此前的修复**：接口错误人性化（4.9）、滚动状态导致的 100% CPU 卡死（5.0）、
  语音结束后界面空转（5.2：滚动/波形/电平限流 + 主线程心跳）、
  `⌘↩` 替换 / `⌘C` 复制 / `⌘R` 重译、剪贴板保存与恢复。

## 安装

1. 打开 DMG，把 `KoK.app` 拖进「应用程序」。
2. 首次启动：菜单栏图标出现后，右键 →「设置…」，添加服务商并填入 API Key。
3. 按提示授予「辅助功能」（翻译选区）和「屏幕录制」（截图并复制）权限。

需要 **macOS 15.7 及以上**。

## 签名说明

当前包使用 Developer ID 签名，但**尚未公证**。如果首次打开被 Gatekeeper 拦下：

- 右键 `KoK.app` →「打开」→ 再点「打开」；
- 或到「系统设置 ▸ 隐私与安全性」→「仍要打开」。

不要为了这个 App 全局关闭 Gatekeeper。

## 已知限制

- 需要自备 API Key（DeepL / Gemini / OpenAI 兼容服务均可）。
- Windows 版暂未提供；路线见 `docs/windows-port.md`。
- 语音识别使用系统 `SFSpeechRecognizer`，中英混说仍在持续改善。
